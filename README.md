# ✦ SVG Icon Exporter (SVG 线性图标生成与下载器)

一个专为硬件、分销及软件平台打造的高品质线性 SVG 图标设计、自定义及批量导出工具。

## 🌟 特性 (Features)
- 🎨 **实时样式调节**：支持修改主要线条颜色、高亮辅助色、线条粗细 (stroke-width) 及导出尺寸 (px)。
- 🔍 **分类与分类搜索**：包含分销与零售、软件与应用、定制解决方案、硬件特征、计算与 AI 模组等分类。
- 📦 **快捷导出**：一键复制 SVG 源代码，或打包下载为 `.svg` 矢量图形文件。
- 🌓 **深浅色主题**：内置 Sleek Dark 与 Light 两种现代调色板。
